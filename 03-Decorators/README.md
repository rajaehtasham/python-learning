# 03 - Decorators

Decorator and closure practice from
Corey Schafer's Python Decorator tutorial
(YouTube)

## What I learned
- Closures — inner function remembering outer variable
- Function decorators
- *args and **kwargs in decorators
- Class decorators using __init__ and __call__
- How @ syntax works under the hood
- Wrapper functions and how they add behaviour

## Files included
- closure_example.py — closure concept
- decorator_func_with_args.py — function decorator
  with *args and **kwargs
- class_and_function_decorator.py — class decorator
  using __init__ and __call__

## Key concept
A decorator wraps a function to add extra behaviour
before or after it runs — without modifying the
original function itself.
